# Guage

A clean and simple front-end for large-language models.

## Notable Features

- SQLite backend by default, Postgres optional
- Drizzle ORM
- TypeScript
- Next.js (for now)
- Tailwind CSS
- Multiple LLM providers (OpenAI, Ollama, more coming)
- Themes

## Usage

### Docker (recommended)

Run with docker

### Manual

```bash
# .env
AUTH_SECRET=
OPENAI_API_KEY=
```
